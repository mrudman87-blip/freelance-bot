#  Настройки бота поиска заказов
#
#  Править можно прямо здесь (на GitHub: значок карандаша → Commit changes)
#  или командами в Telegram: /add, /del, /ban, /budget, /pause, /resume.
#
#  Как писать слова:
#   - одна строка = одно слово или НАЧАЛО слова:
#     «приложени» найдёт «приложение», «приложения», «приложений»;
#   - большие и маленькие буквы не важны, «ё» = «е»;
#   - несколько слов подряд тоже можно:
#     «оформлени документ» найдёт «оформление документов»;
#   - слово в кавычках ищется только целиком: "word" найдёт «Word»,
#     но не «WordPress»;
#   - строки, которые начинаются с #, — это комментарии, бот их не читает.
#
#  Заказ присылается, если в его НАЗВАНИИ или КАТЕГОРИИ есть хотя бы одно
#  слово из любой темы и нет ни одного стоп-слова.
# ============================================================
