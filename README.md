# Бот поиска заказов на фриланс-биржах

Каждые ~10 минут проверяет **Kwork**, **FL.ru** и **Freelance.ru**, отбирает заказы по
ключевым словам и присылает новые в Telegram: название, бюджет, описание, категорию и кнопку
«Открыть заказ».

Работает бесплатно в облаке GitHub Actions, компьютер может быть выключен.

## Что где лежит

| Файл | Что это |
|---|---|
| `settings.txt` | **Темы, слова, стоп-слова, мин. бюджет, пауза.** Править можно прямо на GitHub или командами в Telegram |
| `bot.py` | Сам бот: проверка, фильтр, отправка, команды |
| `sources.py` | Чтение заказов с каждого сайта |
| `.github/workflows/check.yml` | Расписание запуска в облаке (каждые 10 минут) |

## Команды в Telegram

Бот отвечает при следующей проверке, то есть в течение 10–15 минут.

- `/list` — темы, слова и настройки
- `/add слово` — искать ещё и это слово (можно несколько через запятую)
- `/del слово` — больше не искать это слово
- `/ban слово` — не присылать заказы с этим словом
- `/budget 3000` — не присылать заказы дешевле 3000 ₽ (`/budget 0` — присылать все)
- `/pause` и `/resume` — замолчать и снова присылать
- `/status` — когда была последняя проверка, все ли сайты работают

## Как устроен поиск

- Слово ищется с начала слова: `приложени` найдёт «приложение», «приложения».
- Несколько слов подряд: `оформлени документ` найдёт «оформление документов».
- Слово в кавычках ищется только целиком: `"word"` найдёт «Word», но не «WordPress».
- Поиск идёт по названию и категории заказа. Чтобы искать ещё и в описании, поставь
  `искать_в_описании = да`. Заказов станет больше, но и мусора тоже.
- Стоп-слова (спам вроде «оставить отзыв») проверяются в названии и категории.

## Настройка с нуля

1. В Telegram открыть **@BotFather** → `/newbot` → придумать имя → получить **токен**.
2. Написать своему боту `/start`.
3. Узнать свой chat id: в папке бота создать файл `.env` со строкой `TELEGRAM_TOKEN=токен`
   и запустить `python bot.py --chat-id`.
4. На GitHub: **Settings → Secrets and variables → Actions → New repository secret**,
   добавить два секрета: `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`.
5. Вкладка **Actions** → «Поиск заказов» → **Run workflow**. Через минуту в Telegram придёт
   приветствие и несколько заказов для примера.

Репозиторий должен быть **публичным**: тогда GitHub Actions бесплатны без ограничений.
В приватном бесплатно только 2000 минут в месяц, это примерно проверка раз в 30 минут.
Токен хранится в секретах и в публичном репозитории не виден.

## Запуск на своём компьютере

```
python bot.py --dry      # показать, какие заказы сейчас подходят (без Telegram)
python bot.py            # одна проверка с отправкой в Telegram (нужен .env с токеном и chat id)
```

Нужен только Python 3.10 или новее, сторонние библиотеки не используются.
